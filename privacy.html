Политика конфиденциальности

Мобильное приложение «Школьные анекдоты»

← На главную

Дата вступления в силу: 23 октября 2026 г.

Настоящая Политика описывает, как обрабатываются данные в мобильном приложении «Школьные анекдоты» (далее — Приложение), установленном на мобильное устройство пользователя.

1. Оператор данных

Разработчик Приложения — владелец репозитория takomak2012-cyber/SchoolJokes. Способы связи указаны в разделе 8.

2. Какие данные обрабатываются

Приложение не требует регистрации, не создаёт учётных записей и не собирает персональные данные (имя, фамилию, телефон, адрес, платёжные данные и т. п.).

2.1. Данные, которые хранятся только на устройстве в локальных настройках приложения:

  • количество показанных шуток;
  • дата первого запуска;
  • отметки о напоминаниях об оценке приложения;
  • факт перехода в RuStore для оценки.

Эти данные не передаются в интернет и не покидают устройство. Они удаляются вместе с приложением.

2.2. Реклама. В Приложении отображается реклама Рекламной сети Яндекса (РСЯ) через Yandex Mobile Ads SDK. Для детской аудитории персонализация рекламы отключена, установлены возрастные ограничения. Рекламный SDK может автоматически обрабатывать технические данные: IP-адрес, тип и версию устройства, версию ОС, идентификаторы рекламы, а также сведения о взаимодействии с рекламными блоками. Обработка выполняется в соответствии с политикой конфиденциальности Яндекса: https://yandex.ru/legal/confidential/

2.3. Разрешения приложения:

  • доступ в сеть (INTERNET, ACCESS_NETWORK_STATE) — только для загрузки рекламных блоков.

Приложение не запрашивает доступ к камере, микрофону, контактам, геолокации, уведомлениям и файловой системе.

3. Цели обработки

  • обеспечение работы функций Приложения (показ шуток, таймер, копирование и отправка шуток);
  • отображение рекламы, что является единственным источником финансирования бесплатного Приложения.

4. Передача данных третьим лицам

Приложение не продаёт, не передаёт и не арендует данные пользователей. Передача возможна только рекламному партнёру (Яндекс) в объёме, необходимом для показа рекламы, в соответствии с его политикой конфиденциальности, а также по требованию законодательства РФ.

5. Хранение и удаление данных

Все настройки хранятся на устройстве пользователя. Облачный бэкап приложением не создаётся. Удаление Приложения с устройства удаляет все локальные настройки и счётчики.

6. Дети

Приложение предназначено для детей 8–12 лет, имеет маркировку 6+ и не собирает персональные данные детей. Реклама показывается с возрастными ограничениями и без персонализации. Приложение не содержит контента для взрослых.

7. Изменение Политики

Политика может обновляться. Актуальная редакция всегда доступна по адресу: https://takomak2012-cyber.github.io/SchoolJokes/privacy.html

8. Обратная связь

По вопросам обработки данных, а также для предложений и сообщений об ошибках используйте страницу поддержки: github.com/takomak2012-cyber/SchoolJokes/issues.
