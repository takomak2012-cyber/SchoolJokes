# Школьные анекдоты — сайт приложения

Сайт-страница мобильного приложения «Школьные анекдоты» (добрые школьных шуток для детей 8–12 лет).

- Сайт: https://takomak2012-cyber.github.io/SchoolJokes/
- Приложение в RuStore: https://www.rustore.ru/catalog/app/com.windak.schooljokes
- Версия приложения: 1.1.16
- Политика конфиденциальности: https://takomak2012-cyber.github.io/SchoolJokes/privacy.html

## Структура

```
index.html                    главная страница
privacy.html                  политика конфиденциальности
download/SchoolJokes_*.apk    файл приложения для прямой загрузки
assets/style.css              стили (тёмная тема в палитре приложения)
assets/icon-512.png           иконка приложения 512×512
assets/screen-*.png           скриншоты экранов приложения
```

Сайт статический, внешних зависимостей нет, публикуется через GitHub Pages из корня репозитория.

## Обновление версии

1. Соберите подписанный APK и положите его в `download/SchoolJokes_<версия>.apk`
   (предыдущий файл можно удалить, чтобы репозиторий не рос).
2. В `index.html` обновите: ссылку в кнопке «Скачать напрямую (APK)», атрибут
   `download`, пункт «Версия» в списке фактов.
3. В `README.md` обновите номер версии.

## Подтверждение прав для РСЯ

В корне сайта размещается файл подтверждения, который выдаёт консоль РСЯ
(имя и содержимое файла индивидуальны). После получения кода из консоли:

1. Создайте в корне файл с указанным именем (например, `yandex_XXXXXXXX.html`).
2. Вставьте в него выданное содержимое без изменений.
3. Выполните `git add`, `git commit`, `git push`.
4. В консоли РСЯ нажмите «Проверить».

## Файлы для рекламной сети Яндекса (РСЯ)

В корне сайта лежат два служебных файла, выданных консолью РСЯ
(«Настройки → Общие → app-ads.txt»):

```
app-ads.txt   список продавцов рекламы для приложений (проверяется по адресу
              https://takomak2012-cyber.github.io/SchoolJokes/app-ads.txt)
ads.txt       список продавцов рекламы для сайта
```

Содержимое файлов менять не нужно — публикуется как есть. Файл один для всех
приложений, у которых в карточке магазина указан этот сайт.

## Как обновить

```
git add -A
git commit -m "Обновление сайта"
git push
```

GitHub Pages опубликует изменения автоматически в течение минуты-двух.
