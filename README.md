# Школьные анекдоты — сайт приложения

Сайт-страница мобильного приложения «Школьные анекдоты» (2000 добрых школьных шуток для детей 8–12 лет).

- Сайт: https://takomak2012-cyber.github.io/SchoolJokes/
- Приложение в RuStore: https://www.rustore.ru/catalog/app/com.windak.schooljokes
- Версия приложения: 1.1.4
- Политика конфиденциальности: https://takomak2012-cyber.github.io/SchoolJokes/privacy.html

## Структура

```
index.html            главная страница
privacy.html          политика конфиденциальности
assets/style.css      стили (тёмная тема в палитре приложения)
assets/icon-512.png   иконка приложения 512×512
assets/screen-*.png   скриншоты экранов приложения
```

Сайт статический, внешних зависимостей нет, публикуется через GitHub Pages из корня репозитория.

## Подтверждение прав для РСЯ

В корне сайта размещается файл подтверждения, который выдаёт консоль РСЯ
(имя и содержимое файла индивидуальны). После получения кода из консоли:

1. Создайте в корне файл с указанным именем (например, `yandex_XXXXXXXX.html`).
2. Вставьте в него выданное содержимое без изменений.
3. Выполните `git add`, `git commit`, `git push`.
4. В консоли РСЯ нажмите «Проверить».

## Как обновить

```
git add -A
git commit -m "Обновление сайта"
git push
```

GitHub Pages опубликует изменения автоматически в течение минуты-двух.
